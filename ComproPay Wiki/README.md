# ComproPay Wiki

Central de ajuda da ComproPay em HTML estático, sem build. São 26 perguntas
sobre o app, com busca, filtro por categoria e uma página por resposta.

| Peça | O que é |
|---|---|
| [`detalhes/`](detalhes/index.html) | A capa do projeto, que é o que o índice do repositório abre |
| [`index.html`](index.html) | A central: busca, categorias e lista de perguntas |
| [`perguntas/`](perguntas/) | Uma página por pergunta |
| [`assets/`](assets/) | CSS e JS do site, logos |
| [`DS wiki/`](DS%20wiki/) | Só o necessário do design system (tokens, componentes, ícones, fonte Satoshi) |

As respostas vêm da central atual (areacliente.compropay.com.br). O gerador
das páginas fica no projeto local e não foi publicado.
