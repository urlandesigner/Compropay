# Maquininha Roxinha

Protótipo navegável do terminal de uma maquininha Compropay. Uma única
página HTML, com as 22 telas trocadas dentro de uma moldura de terminal por
um pequeno roteador de telas (`support.js`), sem build e sem dependência de
servidor.

## As peças

| Peça | O que é |
|---|---|
| [`detalhes/`](detalhes/index.html) | A capa do projeto, que é o que o índice do repositório abre |
| [`index.html`](index.html) | O terminal, com as 22 telas: PIN, cobrança, aprovação, estorno, relatórios, configurações e ajuda |
