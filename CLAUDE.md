# Instruções para agentes

Este repositório é o índice dos projetos da ComproPay. O `README.md` descreve
a estrutura e os comandos; leia antes de mexer.

## Texto de apresentação

Ao escrever ou revisar a descrição de um projeto — o `--desc` do registro, o
`<meta name="description">`, os parágrafos de abertura e os cartões da capa
(`<Pasta>/detalhes/`) — descreva o que o projeto é, para quem e o que dá para
fazer nele. Não use quantidade (perguntas, telas, categorias, componentes),
lista de itens nem histórico do trabalho: esses textos não podem precisar de
edição quando o projeto crescer. Detalhes e exemplos em "Texto de apresentação
não envelhece", no `README.md`.
